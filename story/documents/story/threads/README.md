# Threads — Rendered trees (Story KB)

Status: skeleton

When a cluster of **garden** notes matures, you say **Render** and I collapse it into a clean
**tree** here — an outline, an arc, a sequence. This is the *present* half of "graph to grow,
tree to present": the garden stays a web; a thread is a deliberate linear/hierarchical view cut
from it for a purpose (a pitch, an outline, an act breakdown). The procedure is the `render-thread`
skill.

- A thread is **canon-adjacent**: it reflects agreed structure, not raw ideation.
- It **links back** to the garden notes it was Rendered from (so the web stays reachable).
- A thread is not the manuscript — finished prose leaves as a **story block** to your external draft.
