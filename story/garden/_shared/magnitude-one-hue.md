# Magnitude = one hue, never a rainbow  (cross-piece motif)

A quantity gets a **single-hue sequential ramp**, never a categorical rainbow; a *kind* gets a
categorical hue. The heat-map refuses rainbow-for-magnitude; the type-coding palette uses distinct
hues for distinct *kinds*. Same underlying discipline: **colour never lies about what kind of
variable it is.**
