# Render from data, don't store the artifact  (cross-piece value)

The body figure is drawn **client-side from the muscle data** — there's no stored muscle-diagram
image (the `exercises.visualization` column is left vestigial). Deterministic, themeable, offline, no
licensing. A "we built the harder-but-righter thing" beat.

It rhymes across the app: type-coding's **hand-rolled glyphs** (no icon library), circuits' live
position **derived from logged set counts** (not stored as a cursor). A recurring design value:
**derive/render over store.**

Cross-piece — will link to the glyph and circuit notes when those pieces are gardened.
