# The builder names the model at the point of creation

Creating a circuit, the numbered selection chips make **selection order = round order**, shown live,
and the copy states the model plainly — *"one set of each per round, in this order."* It names the
concept exactly where you'd otherwise be confused by it.

**Vet:** "names" not "teaches" — it's one well-placed caption + the live chips, not a tutorial. Don't
overclaim pedagogy.
