# The circuit as a box + a dot-grid scorecard

Aesthetically the circuit is a **bounded card** — "your box" — which matches the mental model (a loop
you cycle through). Its heart is the **dot-grid**: rounds × exercises as fillable dots, the current
one ringed — a scorecard that shows the whole 2D progress space in one glance, so you always know
*which exercise, which round*. It borrows the app's existing semantic palette (Command-Blue active,
emerald complete, amber PR) rather than inventing — circuits read as part of the system.
