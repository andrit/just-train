# Act Zero — round-major was a modality the flat model couldn't express

Before circuits, a session was **exercise-major** blocks: all sets of A, then all of B. A circuit is
a fundamentally different **execution order** — one set of each per round, interwoven — that the flat
model simply couldn't represent. So logging a circuit meant faking the interleave by hand or losing
the structure entirely. Circuits make that order **first-class**.

Built by **composition**, not duplication: the live member input reuses `ExerciseBlock`, so per-side,
prefill, and cardio all come for free — the exercise atom rearranged into a new structure.

**Honest scope:** "first-class" is true for *one modality's* circuits — v1 is resistance-only
([[circuits-v1-scope]]). The most common real-world circuit (bodyweight/HIIT) is still excluded.
