# Affordance pluralism — many paths to one value

Type, tap the −/+, hold-to-jump in ×5 coarse steps, drag — several ways to reach the same number,
meeting the user where they are (precise → type; nudge → tap; big jump → hold). *"Steppers are an
adjunct, not the only way in"* is stated as a principle in the code. The point isn't one perfect
control; it's that no single path is the only one.
