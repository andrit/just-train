# The editor morphs to the modality

The target config changes shape by workout type: resistance → Sets × Reps × Weight; cardio → Rounds +
Distance / Time / Intensity; calisthenics → Sets × Reps *or* Time; stretching → Sets × Hold; cooldown →
Duration. The input surface speaks each type's **native metric** — the data-level companion to
type-coding's *visual* differentiation of types ([[type-coding-trust-via-visual-language]]): types
don't just look different, they *are captured* differently.
