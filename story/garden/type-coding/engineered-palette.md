# The palette is engineered, not chosen by taste

ΔE ≥ 15 on every pair, contrast ≥ 3:1 on both grounds, CVD separation in the 6–8 band (legal *because*
every surface pairs colour with an icon + label — see [[triple-redundant-encoding]]). "Pretty" is a
byproduct of "provably distinguishable." Same discipline the body map follows from the other side
([[magnitude-one-hue]]): categorical hue for *kind*, sequential ramp for *magnitude*.

**Honest nuance (carry to the report):** the palette is also **constraint-driven**, not purely
intentional — the one free CVD-safe slot between red and blue is magenta, which is *why* calisthenics
is fuchsia ([[fuchsia-kept-decision]]). Engineered *and* forced; don't oversell "designed."
