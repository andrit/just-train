# Hand-rolled glyphs — rendering in its own hands

Five SVG glyphs drawn by hand (no icon library): barbell, bicycle, jumping-jack, split, snowflake.
Buys uniform weight/viewBox/stroke, zero dependency, and the Barlow-Condensed "gym-poster" line. Four
are literal depictions; one is a metaphor (snowflake = cool-down) — writer kept it ("steam rising"
works too). Same instinct as the body map rendering from data ([[render-from-data-not-stored]]): the
app keeps its rendering in its own hands rather than importing assets.
