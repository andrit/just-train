# Act Zero — two colour maps that disagreed

Before #25 there were **two** type-colour maps (`WORKOUT_TYPE_COLOR` + `WORKOUT_TYPE_BADGE_VARIANT`)
that could paint the **same type two different colours** — a card and its badge disagreeing. So the
Act Zero isn't "no colour coding"; it's **colour coding that contradicted itself.** For an app whose
pitch is a trustworthy progress *narrative*, a visual vocabulary that lies about its own categories is
a credibility leak. #25 is as much a **consolidation** as a visual feature.
