# Type coding = trust/consistency, delivered through a visual language

**Headline (writer-locked).** The feature isn't "we added colours." It's a *visual language* that
makes the app's categories trustworthy and legible. Two layers deliver it: the **one source of truth**
under the hood ([[one-source-of-truth]]) makes the vocabulary *consistent*; the **colour + glyph +
label** on the surface make it *legible*. Trust is the product; colour is how it's expressed.
