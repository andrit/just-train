# Unknown type → neutral slot (fail-safe)

`exerciseTypeTheme(type)` returns the cooldown/slate entry for any unrecognised type — the deliberate
**neutral/null slot**. An unknown type degrades to "no signal," never to a *wrong-colour* signal.
Failure is designed, not accidental. This is type coding's version of the spine
([[honest-representation]]): the UI degrades safely, same family as circuits' derived state and the
body map's render-from-data.
